# RPA Pogoda Kielce — automatyzacja przeglądarki Firefox w C#

Prosta aplikacja konsolowa napisana w C#, która wykorzystuje Selenium WebDriver do uruchomienia przeglądarki Firefox i wyświetlenia aktualnej pogody dla Kielc.

W systemie powinny być zainstalowana przegladarka Firefox.

## Jak uruchomić projekt
```bash
dotnet restore
dotnet run
